# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité dans Les Bases du numérique d'intérêt général, merci de ne pas la rendre publique (issue, pull request, discussion) avant sa correction.

Signalez-la de façon confidentielle depuis l'onglet [Security](https://github.com/inclusion-numerique/la-base/security) du dépôt, avec le bouton « Report a vulnerability » (signalement privé GitHub). Décrivez si possible :

- la partie de l'application concernée (URL, page, API) ;
- les étapes pour reproduire le problème ;
- son impact possible.

Le signalement n'est visible que par l'équipe, qui en accuse réception et vous tient informé de son traitement.

## Contributeurs

Les membres de l'équipe traitent les incidents de sécurité selon la procédure décrite dans le [guide de contribution](./CONTRIBUTING.md#incidents-de-securite).
